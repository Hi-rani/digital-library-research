# 2016~2025년 국내 디지털 도서관 연구 동향 분석
## 부제: 핵심 키워드와 주제 변화

본 프로젝트는 한국학술지인용색인(KCI)에서 수집한 최근 10개년(2016~2025년) '디지털 도서관' 관련 학술 논문 213편을 대상으로 계량서지학(Bibliometrics) 및 텍스트 마이닝(Text Mining)을 수행하고, 대학 수업 및 연구 발표에 즉시 활용할 수 있도록 제작된 **16:9 와이드 학술 프레젠테이션(HTML Slides)** 패키지입니다.

---

## 1. 프로젝트 주요 특징

- **엄격한 데이터 무결성 검증**: 원본 엑셀(`KCI_excel_2026432443058.xls`)의 213편 전건에 대해 중복률 0%, 연도 부합률 100%를 검증하였으며, 원본 파일은 일절 수정하지 않고 보존하였습니다.
- **체계적인 키워드 정규화**: 942개 원시 키워드의 대소문자, 단복수, 띄어쓰기 및 명백한 영·국문 동일어를 정규화하여 `keyword_normalization_rules.csv`에 전수 기록하였습니다.
- **재현 가능한 Python 파이프라인**: Pandas, Kiwi(형태소 분석기), Scikit-Learn(TF-IDF/LDA), NetworkX를 활용하여 전처리부터 분석, 300 DPI 고해상도 시각화까지 전 과정을 자동화하였습니다.
- **현대적 학술 디자인의 HTML 슬라이드**: 모든 슬라이드 배경을 흰색(#FFFFFF)으로 통일하고, 16:9 와이드 비율의 세련된 타이포그래피와 반응형 레이아웃을 적용하였습니다.
- **완전한 로컬 독립 구동**: 외부 CDN이나 백엔드 서버 없이 웹 브라우저에서 즉시 열어 발표할 수 있습니다.

## 3. HTML 슬라이드 실행 및 조작 방법

### 실행 방법
별도의 웹 서버 설치나 인터넷 연결 없이, 로컬 폴더의 **`index.html` 파일을 크롬(Chrome), 엣지(Edge), 사파리(Safari), 웨일(Whale) 등 최신 웹 브라우저에서 더블 클릭**하면 즉시 프레젠테이션이 실행됩니다.

### 발표 조작 안내
| 기능 | 단축키 / 마우스 조작 |
| :--- | :--- |

## 5. 핵심 연구 발견 요약

1. **후기 연구 집중**: 2016~2025년 총 213편 중 46.5%(99편)가 후기(2022~2025년)에 집중되었으며, 2023년에는 28편으로 최고치를 기록했습니다.
2. **디지털 리터러시의 부상**: `디지털 리터러시`(23편, 10.95%)가 `디지털도서관`과 공동 1위를 차지하여, 시스템 인프라 구축 중심에서 이용자 정보 역량 강화로 연구 중심축이 이동했습니다.
3. **관종별 밀착형 연구**: 공공도서관(18편), 대학도서관(17편), 학교도서관(12편) 순으로 고르게 연구되었으며, 특히 대학도서관은 후기에만 11편이 발표되며 급격히 성장했습니다.
4. **다학제적 융합**: 문헌정보학(52.1%)을 중심으로 실내디자인(공간 설계), 컴퓨터공학(검색 시스템), 어문학/역사학(디지털 아카이브) 등 47개 학문 분야에 걸쳐 폭넓게 연구되었습니다.
5. **3대 지식 네트워크 군집**: 키워드 동시 출현망 분석 결과 ① 이용자 리터러시 교육 군집, ② 도서관 관종별 공간/서비스 군집, ③ 전자자원 저작권·라이선스 군집의 세 기둥이 유기적으로 결합되어 있음을 입증했습니다.

python scripts/make_charts.py

# 4. 데이터 무결성 및 산출물 종합 검증
